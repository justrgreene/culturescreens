# Culture on Screens

A responsive, five-page editorial website template for GitHub Pages. It uses plain HTML, CSS, and JavaScript—no build step or dependencies required.

## Pages

- `index.html` — home page
- `about.html` — about the journal
- `images.html` — content page: images
- `stories.html` — content page: stories
- `signals.html` — content page: signals

## Edit the site

Open the HTML files in any text editor to change page titles, copy, navigation, and story content. Shared layout and visual styling live in `styles.css`; menu behavior, scroll reveals, and subtle scroll movement live in `script.js`.

The newsletter form is a front-end placeholder and does not collect addresses. Connect it to an email service before using it. The display fonts load from Google Fonts; system sans-serif fallbacks are included.

## Publish with GitHub Pages

1. Add these files to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch and `/(root)`, then save.
4. Open the published Pages URL after GitHub finishes deployment.

The pages use relative links, so the template also works when published from a repository subpath.
